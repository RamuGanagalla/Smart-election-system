# Smart Election Admin Portal

A polished React/Vite admin dashboard for the Smart Election System.

## Included
- Admin login UI
- Dashboard with election statistics
- Election management
- Voter registration and search
- Candidate management
- Election reports
- Settings page
- Responsive sidebar/navigation
- Mock data
- Modal forms
- Lucide icons
- Responsive design

## Run

```bash
npm install
npm run dev
```

The portal is currently a frontend-only prototype using mock data.

## Planned backend integration

The existing Node/Express backend can later provide:
- Admin authentication
- Election CRUD
- Voter CRUD
- Candidate CRUD
- Reports
- Vote statistics

Do not put real credentials in the frontend. The current login is only a UI prototype.
